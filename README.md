# Solar System Canvas Simulation

An interactive 2D Solar System simulation built using HTML5 Canvas and vanilla JavaScript for a school project.

## Features
* **Orbital Motion**: Simulates the orbits of all 8 planets and Earth's Moon around the Sun using trigonometric positioning.
* **Interactive Info Cards**: Click on any planet to open an overlay showing its mass, diameter, and orbital period (double-click anywhere to dismiss).
* **Real Scale Toggle**: Switch between visual size modes and scaled planetary proportions relative to the Sun.
* **Speed Control**: Adjust simulation speed using an interactive range slider.
* **Orbit Paths**: Toggle visual orbital tracks on and off.
* **Procedural Background**: Generates a random starry background on each frame render.

## Tech Stack
* HTML5 / Canvas API
* Vanilla JavaScript (ES6)
* CSS3

## How to Run
1. Clone or download the repository.
2. Ensure `mojefunkcije_01.js` is in the same directory.
3. Open `index.html` in any modern web browser.
